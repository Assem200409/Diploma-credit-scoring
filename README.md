# Forecasting bank lending risks using artificial intelligence technologies
## Приложение
Демо-версия доступна по ссылке (в разработке): https://diploma-credit-scoring-xjylmxiwrq7eu2nde5eiha.streamlit.app/
## Описание проекта
Проект посвящен прогнозированию кредитного риска заемщиков банка с применением методов машинного и глубокого обучения.
Основная задача: выявить закономерности платежной дисциплины и построить модели машинного и глубокого обучения для прогнозирования вероятности дефолта (риска невозврата кредита).
Проект связан с задачами кредитного скоринга, риск-аналитики и анализа клиентской базы.
## Данные
В проекте использовались обезличенные данные заемщиков банка.
Объем данных: 3 млн клиентов, 61 признак.
## Проделанная работа
В рамках проекта было проведено следующее:
- предобработка данных;
- статистический анализ (определение аномальных клиентов, тест Колмогорова-Смирнова, тест Фишера);
- визуализация данных;
- построение и сравнение моделей машинного и глубокого обучения (Decision Tree, Random Forest, Gradient Boosting, Neural Network);
- оценка качества моделей (precision, recall, accuracy, f1-score, ROC-AUC, Precision-Recall AUC, confusion matrix).
## Результаты исследования
В результате исследования были выявлены клиенты, формально относившиеся к недефолтным заемщикам, но при этом их платежная дисциплина демонстрировала признаки повышенного кредитного риска.
После переклассификации клиентов качество прогнозирования существенно улучшилось. Наилучшие результаты показали модели Random Forest и Decision Tree.
## Практическая значимость
Данный проект полезен для задач кредитного скоринга и риск-аналитики.
